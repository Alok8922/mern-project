## 📌 Overview

The **Smart Campus Placement Portal** is a modern web application built using the **MERN Stack** that simplifies and automates the campus recruitment process.

🔹 Students can apply for jobs
🔹 Companies can manage job postings & applicants
🔹 Admin controls the entire system

---

## 🛠 Tech Stack

### 🚀 Frontend

* ⚛️ React.js
* 🔁 React Router
* 📡 Axios

### 🔧 Backend

* 🟢 Node.js
* 🚂 Express.js
* 🍃 MongoDB (Atlas)

### 🔐 Authentication

* 🔑 JWT (JSON Web Tokens)
* 🔒 Role-Based Access Control

### ☁️ Deployment

* 🌐 Render (Frontend + Backend)
* 🗄 MongoDB Atlas

### 👨‍🎓 Student Panel

### 🏢 Company Panel

## ⚙️ Environment Variables

Create a `.env` file in `mern/backend`:

```
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
EMAIL_USER=your_email
EMAIL_PASS=your_password
```

## 🚀 Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Alok8922/mern-project.git
cd mern-project
```

### 2️⃣ Install dependencies

📦 Backend:

```bash
cd mern/backend
npm install
```

📦 Frontend:

```bash
cd ../../frontend
npm install
```

---

### 3️⃣ Run the project

▶️ Backend:

```bash
cd mern/backend
npm start
```

▶️ Frontend:

```bash
cd ../../frontend
npm start
```
